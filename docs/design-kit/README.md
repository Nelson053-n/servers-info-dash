# Набор дизайна «info» для другого агента

Пульт инфраструктуры в стиле «стойка с индикаторами»: графит и сталь, цвет только для состояния, моноширинные цифры,
прямые формы, линии вместо теней. Здесь всё, чтобы поднять такой же вид и такую же инфографику в другом сервисе.

**Начните с `demo.html`** — откройте файл в браузере (сервер не нужен). Это эталон: плитки, карточка дохода, линия,
столбики со стеком, таблица со статусами; переключатель тёмной/светлой темы и 6 акцентов. Снимки: `preview-dark.png`, `preview-light.png`.

## Состав

| Путь | Что это |
|---|---|
| `demo.html` | живой эталон на тестовых данных |
| `css/tokens.css` | цвета и шрифты (тёмная тема, `:root.light`, акценты `:root.clr-*`) |
| `css/fonts.css` + `fonts/` | свои копии IBM Plex Sans/Mono и Martian Mono (внешние шрифты CSP не пускает; лицензии OFL) |
| `css/shell.css` | базовая вёрстка: карточки, плитки, графики, таблицы, меню |
| `css/tech.css` | слой «стойка»: радиусы 2–4 px, моноширинные подписи, линии, лента парка, подсветки |
| `css/base.css` | кнопки, поля, таблица, всплывашки (в оригинале — inline `<style>`, идёт последним) |
| `js/charts.js` | автономный модуль: `window.InfoUI = {drawChart, kpiStat, stat, chip, fmtValue, el, svg, nf}` |
| `analytics-schema.md` | формат данных проекта (kpis, charts, tables, alerts) |
| `tests/` | примеры jsdom-тестов интерфейса |

Порядок подключения строго такой: `fonts.css → tokens.css → shell.css → tech.css → base.css`. `tech.css` грузится после `shell.css` и
переопределяет его; `base.css` — последним.

## Принципы (то, что делает вид узнаваемым)

1. **Цвет = состояние.** Зелёный `--ok`, янтарь `--warn`, красный `--bad`. Всё остальное — сталь и графит. Акцент (`--accent`) — один, он
   только для выбранного, ссылок, фокуса и первой серии графика. Смена акцента меняет **только** `--accent`; поверхности
   (`--bg/--panel/--rail/--line`) остаются стальными, иначе боковая панель и контент получают разные оттенки.
2. **Линии вместо теней.** Рамки 1 px `--line`, внутренние разделители `--line2`, радиусы 2–4 px (чипы 2 px), теней нет.
3. **Числа и подписи — моноширинные** (Martian Mono, сужен `font-stretch:88%`), с `font-variant-numeric:tabular-nums`; текст — IBM Plex Sans.
   Подписи плиток 11–12 px `--muted`; значение плитки 24–34 px, вес 500, `letter-spacing:-.03em`. Длинное «значение-текст» (например «работает»)
   выводится шрифтом Sans 20 px (`isLong()` решает сам).
4. **Плотность.** Плитки склеены одной линией (`.stats{gap:1px;background:var(--line)}`), таблицы без зебры, строки 11 px по вертикали.
5. **Тема.** Тёмная по умолчанию, светлая — класс `light` на `<html>`; все цвета только через переменные, графики тоже
   (`fill="var(--accent)"` в SVG).

### Токены

Тёмная: `--bg #090B0E`, `--panel #0E1217`, `--panel2 #141A21`, `--rail #07090B`, `--line #1C242D`, `--line2 #151B22`, `--text #E4E9EE`,
`--text2 #B4BEC9`, `--muted #76828F`, `--faint #505B67`, `--ok #35D399`, `--warn #F0B030`, `--bad #FF5444`, `--accent #A9BDD0`;
текст на статусах: `--ok-fg #5BE0AE`, `--warn-fg #F5C35A`, `--bad-fg #FF8073`.
Светлая: `--bg #E8ECEF`, `--panel #F6F8F9`, `--text #11171D`, `--ok #17935F`, `--warn #B87100`, `--bad #D23A2B`, `--accent #3B556E` и т. д. (см. `tokens.css`).
Акценты: purple `#8b5cf6`, emerald `#10b981`, rose `#f43f5e`, amber `#f59e0b`, cyan `#06b6d4` (в светлой теме темнее).

## Инфографика

Графики — свой SVG без библиотек (`drawChart(box, chart, {spark})`), формат `chart`:
`{kind: "line"|"bar", unit: "₽", series: [{name, points: [[x, y], …]}], title?, note?}`; `x` — `YYYY-MM`, `YYYY-MM-DD` или ISO-время.

Правила, которые уже зашиты (повторять не надо, но нужно знать):
- несколько серий `bar` → **столбики со стеком** + легенда + строка «Всего» в подсказке; серия с именем `fail/ошиб/error/отказ` красится в `--bad`;
- палитра серий: `--accent`, `--warn`, `#14b8a6`, `#a855f7`, `--muted`;
- `line` с одной серией — линия 2 px и заливка 12 %; если значения далеко от нуля (курс, стоимость), ось идёт по диапазону данных, иначе линия плоская;
- помесячный ряд: пустые месяцы до первых данных не показываются; подписи оси — «янв, фев…», для дней — `дд.мм`, для часов — `чч:00`;
- ось Y — «красивые» шаги (1, 2, 2.5, 5), подписи сокращаются «тыс/млн», ширина поля под подписи считается по самой длинной;
- подсказка при наведении: вертикальный курсор, значения серий; `spark:true` — мини-график 44 px без осей;
- пустой ряд → «Нет данных за период».

### Карточка дохода (самая узнаваемая)
Заголовок `<проект> — доход` + подсказка справа; крупное значение (`.money-value`, 34 px) с дельтой «▲ +8,2 %» (зелёная/красная) и значением прошлого
периода справа; ниже столбики за 12 месяцев; внизу строка `.money-ytd` «С начала года: …» (сумма месяцев текущего года из того же графика).
Разметка — в `demo.html`, раздел «карточка дохода».

### Таблицы
`.ptable`; колонка `num` выравнивается вправо и форматируется как число; колонка со статусом — `chip` (`ok|warn|bad|off`);
клик по заголовку сортирует (в панели это `.ptable th.sortable`); строка с блокировкой — `tr.blk`, ячейка `td.blocked` красная.

## Как применить в другом сервисе

1. Скопируйте `css/`, `fonts/`, `js/charts.js` в статику; в `<html>` ставьте `class="light"` для светлой темы и `clr-<цвет>` для акцента.
2. Подключите стили в порядке выше и `charts.js`; в странице — контейнер `.content > .view` (колонка с `gap:16px`), внутри `.card`, `.stats`, `.grid2`.
3. Данные приводите к формату `analytics-schema.md` (kpis / charts / tables) — тогда плитки и графики строятся функциями `kpiStat` и `drawChart` без доработок.
4. Для сумм и месяцев используйте `fmtValue(value, unit)`: «114 тыс», «$0,0657», «5 544 ₽».

## Ограничения и грабли

- **CSP**: внешние шрифты и inline-скрипты запрещены → шрифты свои, скрипты отдельными файлами.
- **Кеш**: в оригинале стили/скрипты подключены с `?v=…`; при правке файла версию нужно поднимать.
- Демо тестировалось в Chromium (playwright), ошибок консоли нет; тёмная/светлая темы сверены по снимкам.
- Тесты в `tests/` — jsdom (`npm i --no-save jsdom@24`); они рассчитаны на структуру `app/static` оригинала, как образец подхода (мок `fetch`, проверка DOM),
  а не как готовый набор для другого сервиса. Новый тест всегда проверяйте мутацией: сломайте код и убедитесь, что тест краснеет.
- Что **не** вошло: боковое меню, лента парка серверов (`.fleet-card`), матрицы связности, поиск Ctrl K. Их стили есть в `shell.css`/`tech.css`,
  а разметка — в `app/static/views.js` и `app/static/app.js` оригинала.
