# Формат аналитики проекта (вкладка «Проекты»)

Каждый источник (HTTP-эндпоинт проекта или JSON-файл root-сборщика в
`/var/lib/infodash/projects/<id>.json`) отдаёт один документ. Страница проекта
рисует его без знания о проекте: плитки, графики, таблицы, замечания.

```json
{
  "generated_at": "2026-10-15T03:26:39+00:00",
  "kpis": [
    {"id": "revenue_30d", "label": "Выручка за 30 дней", "value": 15250, "unit": "₽",
     "state": "ok", "delta": 12.5, "delta_label": "к прошлым 30 дням", "hint": "только оплаты в рублях"}
  ],
  "charts": [
    {"id": "revenue_daily", "title": "Выручка по дням", "kind": "bar", "unit": "₽",
     "note": "оплаты ЮKassa, по дате оплаты",
     "series": [{"name": "₽", "points": [["2026-09-16", 500], ["2026-09-17", 0]]}]}
  ],
  "tables": [
    {"id": "servers", "title": "Ноды",
     "columns": [{"key": "name", "label": "Нода"}, {"key": "online", "label": "Онлайн", "num": true},
                 {"key": "state", "label": "Статус", "state": true}],
     "rows": [{"name": "Германия", "online": 12, "state": "ok"}]}
  ],
  "alerts": [{"severity": "warn", "text": "2 открытых SSH-алерта"}]
}
```

Правила:
- `generated_at` — ISO 8601 с поясом. Дашборд считает документ протухшим, если он старше `max_age_min` из конфига.
- `kpis[].value` — число или строка (для статусов вроде «работает»); `unit` — короткая единица: «₽», «$», «%», «шт», «ГБ», «FLUX» или пусто.
  `state`: `ok` | `warn` | `bad` (по умолчанию `ok`). `delta` — изменение в процентах к прошлому периоду, необязательно.
  Первые 4 плитки показываются на карточке проекта на главной — ставь самые важные первыми.
- `charts[].kind`: `bar` (счётчики и суммы по дням) или `line` (уровни: онлайн, CPU, курс).
  `points` — `[дата, число]`; дата `YYYY-MM-DD` для дневных рядов или ISO-время для почасовых.
  Дни считаются по Владивостоку (Asia/Vladivostok, UTC+10) — так пользователь видит сутки.
  Пустые дни заполняй нулём, чтобы ось была непрерывной. До 4 серий на график.
- `tables[].rows` — не больше 50 строк. Колонка с `"state": true` рисуется цветной меткой (ok/warn/bad).
  Колонка с `"num": true` выравнивается вправо и форматируется как число.
- `alerts` — то, что требует действия владельца; `bad` — срочно, `warn` — проверить.
- Никаких персональных данных: имён, телефонов, e-mail, telegram id. Только агрегаты и названия серверов.
- Только чтение у источника: SELECT, `systemctl is-active`, curl к localhost.
